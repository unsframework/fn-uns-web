PLAN A PILOT

Make the first result specific.

  1. Pick a question. For example: how long was CNC-01 running last shift? Agree how you will use the answer.
  2. Agree the meaning. Define “running,” the shift boundary, and how to handle missing data with the people who use the machine.
  3. Choose one source. Identify the signal, its owner, and a way to collect it. Compare the result with an observation or an existing record.
  4. Assign ownership. Name who connects the equipment, manages the software, and checks the result. Expand after the first use is trusted.

WHAT YOU WILL FIND HERE

The description and the software.

UNS Framework is an open standard for describing your factory and its data in YAML files. fn-uns is a working implementation with components for capturing signals, keeping history, and calculating production metrics. fnkit is the tooling used to build and deploy those components.
